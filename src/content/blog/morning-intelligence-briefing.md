在数字化时代，我们每天都在对抗两种力量：**市场情绪的噪音**，以及**信息碎片的侵蚀**。

前者容易诱发追涨杀跌、推翻纪律的非理性投机；后者则以短视频与算法推荐的形式，不断肢解注意力的连续性。为了从根本上解决这两个痛点，我在 2026 年初启动并持续迭代了一个完全基于 Serverless 架构的个人早报自动化工程 —— **Morning Intelligence Briefing（晨间情报内参）**。

每天清晨 09:00（北京时间），在开盘与开始一天深度学习前，一封排版考究、信噪比极高、结构自适应的 HTML 报告会自动投递到我的个人邮箱中。

## 🏛️ 系统拓扑：零成本 Serverless 闭环

很多个人自动化脚本最终死于“服务器月租开销”或“运维停机维护”。本系统在设计之初就立下一条硬性原则：**零固定服务器成本、零繁复外部容器依赖、纯云端免维护。**

```text
Cloudflare Workers Cron / GitHub Actions Schedule (每日 09:00 CST 定时触发)
   │
   ▼
GitHub Actions 自动化执行 Runner (Ubuntu Latest)
   │
   ├─► 1. 行情与估值抓取引擎 ──► 计算 PE/PB 历史百分位与 SMA200 均线
   ├─► 2. 宏观异动扫描器     ──► 抓取 10Y 美债、黄金、费半、USD/CNH 汇率
   ├─► 3. AI 学术雷达       ──► 解析 Hugging Face Papers 当日高票顶会论文
   ├─► 4. 宏观快讯聚合       ──► 抓取 CNBC Economy 等国际经济要闻
   └─► 5. 经济学人精读引擎   ──► 规范化双语原典拆解、语法长难句与词汇搭配
   │
   ▼
内联 CSS 响应式 HTML 渲染引擎
   │
   ▼
SMTP 协议安全推送信道 ──► 个人 QQ 邮箱 (带高亮状态徽章)
```

- **调度端：** 采用 GitHub Actions 定时任务，兼顾 Cloudflare Workers Webhook 冗余唤醒；
- **凭证安全：** `SMTP_USER` 与 `SMTP_CODE` 均保存在 GitHub Repository Secrets，源码不留任何敏感配置；
- **优雅降级（Graceful Degradation）：** 针对海外资讯源或特定行情接口偶发网络波动，模块间完全解耦。任何单一数据源拉取失败时均自动填充缓存或安全缺省值，绝不中断整份早报的渲染与投递。

## 📊 核心量化模型：资产双轴风控法则

在二级市场中，散户亏损的核心根源往往是“用估值去猜顶底，用情绪去管买卖”。本系统推行的是**双轴严格分离的机械化执行模型**：

```text
【轴一：估值评分】 ──决定──► 【新资金定投倍率（仓位控制）】
【轴二：趋势突破】 ──决定──► 【存量资产严格止盈（卖出开关）】
```

### 1. 估值打分驱动动态定投（DCA 调节器）
系统每日根据各标的（纳指100、标普500、沪深300、中证500）当前所处的历史估值百分位（PE-TTM / PB）计算综合估值评分：

| 综合估值评分区间 | 执行定投比例 | 对应市场心理与策略逻辑 |
| :---: | :---: | :--- |
| `< 40%` | **100% 定投** | 极度低估与熊市底部，加大马力收集廉价筹码 |
| `40% ~ 60%` | **75% 定投** | 合理估值中枢偏下，保持平稳买入 |
| `60% ~ 75%` | **50% 定投** | 适度高估，收缩资金暴露 |
| `75% ~ 85%` | **25% 定投** | 高估警惕区，严控增量资金 |
| `≥ 85%` | **0% 定投** | 泡沫化估值区，**全面暂停定投**，杜绝山顶送钱 |

### 2. 趋势确认驱动分批止盈（锁定利润）
很多人常犯的错误是“一高估就卖光”，结果错失主升浪泡沫溢价；或者“死扛到熊市全部利润回吐”。系统的止盈铁律是：
* **硬性条件：** 估值评分 `≥ 95%`，**或**（估值评分 `≥ 90%` 且收盘价连续 2 日跌破 SMA200 且 20 日斜率为负）；
* **执行方式：** 触发后每次分批卖出存量的 `1/3`，卖出间隔为标的继续上涨 `10%`；
* **买卖解耦：** 存量止盈卖出与增量定投互不干扰，止盈资金沉淀至货币/无风险资产。

## 📖 英语精读引擎：《经济学人》规范双语解析

对于计算机与量化学习而言，阅读英语权威一手原典是不可绕过的基本功。但以往打开 APP 很容易因生词过多而中途放弃，或者沦为死记生僻词的低效背诵。

本系统在内参中集成了专门的《经济学人》(The Economist) 精读模块，并严格实施 **“三段独立分块规范”**：

1. **PART 1：英文原文语段**  
   精选当天宏观经济、技术哲学或系统科学领域文笔最具美感的段落；
2. **水平分割线 (`---`) 物理隔离**  
   强制先阅读英文原文，避免视线直接被中文吸引产生依赖；
3. **PART 2：学术精译与硬核词法解析**  
   提供专业中译，并提炼 3~5 个具有高复用价值的 CET-4 / 考研核心高频搭配与复杂语法长难句分析（如倒装、独立主格、伴随状语）。

每天只需在早餐或通勤时精读 5 分钟，积少成多，彻底免去额外的单词背诵软件打卡负担。
